# Titanic Survival Analysis

## Overview
End-to-end data science project analysing survival
patterns from the Titanic dataset using Python.

## Key findings
- Women survived at a significantly higher rate than men
- 1st class passengers had the highest survival rate
- Fare and Age were the strongest predictors of survival

## Project steps
1. Exploratory data analysis (EDA)
2. Data cleaning and feature engineering
3. Random Forest classification model
4. Model evaluation (confusion matrix, F1, CV)
